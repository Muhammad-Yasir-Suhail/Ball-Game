# Ball Collectible Game (Unity)

## 📌 Overview

This is a **2D Unity-based game** where the player controls a ball to collect square-shaped collectibles and reach the final point to complete each level.

The project focuses on physics-based movement, object interaction, and level progression.

---

## 🚀 Features

* Physics-based ball movement
* Collectible system
* Level completion objective
* Collision detection
* Multiple levels

---

## 🛠️ Technologies Used

* Engine: *Unity*
* Language: *C#*
